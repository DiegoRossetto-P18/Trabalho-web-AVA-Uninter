# Projeto Web Front-End 🌐

Aplicação web interativa desenvolvida com tecnologias fundamentais de Front-End (HTML5, CSS3 e JavaScript), focada na criação de interface responsiva e manipulação dinâmica do DOM.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout responsivo e design visual.
- **JavaScript (ES6+):** Lógica de interatividade e manipulação dinâmica de elementos da página.

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação web desenvolvida para praticar conceitos de desenvolvimento Front-End, incluindo estruturação de páginas, estilização moderna e implementação de scripts dinâmicos para interação com o usuário.

## 📁 Estrutura do Repositório

Trabalho-web-AVA-Uninter/
├── index.html        # Estrutura principal da página
├── style.css         # Estilização visual e responsividade
├── script.js         # Lógica e interatividade em JavaScript
└── README.md         # Documentação do projeto

## ⚙️ Como Executar o Projeto

### 1. Acesso via GitHub Pages
O projeto está publicado e pode ser acessado diretamente pelo navegador através do link:
https://diegorossetto-p18.github.io/Trabalho-web-AVA-Uninter/

### 2. Execução Local
1. Clone o repositório:
git clone https://github.com/DiegoRossetto-P18/Trabalho-web-AVA-Uninter.git

2. Acesse a pasta do projeto:
cd Trabalho-web-AVA-Uninter

3. Abra o arquivo `index.html` no seu navegador (ou utilize a extensão Live Server no VS Code).
